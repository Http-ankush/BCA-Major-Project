## 📌 Project Overview

This project focuses on analyzing Ola ride-booking data to uncover valuable business insights related to bookings, cancellations, revenue generation, customer behavior, vehicle performance, payment preferences, and customer satisfaction.

The project demonstrates a complete Data Analytics workflow involving:

- Data Cleaning using Microsoft Excel
- Exploratory Data Analysis (EDA) using Python
- Business Intelligence Dashboard using Power BI

The objective is to transform raw booking data into meaningful insights that support data-driven decision-making.

---

## 🎯 Objectives

- Analyze booking patterns and ride trends.
- Identify cancellation behavior.
- Evaluate revenue performance.
- Understand customer and driver ratings.
- Study payment preferences.
- Create an interactive business dashboard.
- Generate actionable business recommendations.

## 📈 Dashboard Insights

Some major insights identified:

- Most bookings are concentrated in specific vehicle categories.
- Digital payments dominate ride transactions.
- Certain locations generate significantly higher revenue.
- Peak booking hours can be identified.
- Customer and driver ratings influence ride completion rates.
- Ride cancellations impact operational efficiency.
